TMS E-Learning PWA

1. เปิด index.html
2. เปลี่ยน APP_URL เป็น Web App URL เดิมของ Apps Script และเติม ?page=elearning
3. นำทั้งโฟลเดอร์ขึ้น Static Host ที่รองรับ HTTPS
4. เปิด URL แล้วเลือก Install App ใน Chrome/Edge

ชุดนี้เป็น PWA Shell; ระบบเรียนจริงยังใช้ Apps Script เดิม
ไม่ต้องแก้ EmployeePortal.gs / EmployeePortalUI.html / EmployeePortal_Css.html
และไม่ทำให้หน้า E-Learning ของ Apps Script ใช้งานออฟไลน์
